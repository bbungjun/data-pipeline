# Archive

This folder contains material kept for reference but not used as the active log pipeline path.

- `backend-dist/`: compiled backend build output used only as reference.
- `generated-build/`: generated Lambda package/build artifacts kept out of the active source layout.
- `runtime-state/`: local runtime/checkpoint state kept out of the active source layout.
- `terraform_setting-main/`: full-stack Terraform for VPC, EC2, RDS, Lambda, CloudWatch, and OpenSearch. Treat it as historical/reference infrastructure unless you intentionally want to manage the whole stack.
- `_repo_check/`: previous repository check/reference copy.
